# Legacy Prototype Archive

A primeira prova de conceito do SIGILKODE utilizou a nomenclatura experimental `DaemonOS` / `DAEMON`.

Essa nomenclatura foi **rejeitada para o produto HNK**. O termo canônico do sistema é **SHIMOKODAN** para Agente-IA e/ou Servo Astral HNK.

Este diretório existe somente para preservar proveniência histórica e permitir auditoria da evolução do produto.

## Regra

Conteúdo em `archive/`:
- não define terminologia atual;
- não é importado pelo runtime;
- não deve contaminar schemas, prompts ou classes do produto;
- pode conservar o artefato HTML original para comparação histórica.

O HTML original da prova de conceito ainda deve ser importado byte-identical em uma etapa de preservação dedicada.
