# SK-011.2 — Compatibility Bridge + Matrix Engine

Status: implementation candidate

## Purpose

Advance TEHNKÉ-MAGIK V0.2 without rewriting or mutating the legacy SIGIL-IR/V0.1 compiler.

## Compatibility boundary

`bridgeSigilV01ToTehnke()` is an additive adapter. Legacy input is read and translated into `TEHNKE-IR/V0.2`; V0.1 source files remain untouched.

## Matrix execution

`executeMatrixEngine()` consumes only `TEHNKE-IR/V0.2`. Matrix applications preserve declared order and expose explicit `APPLIED` states. Manifestation channels expose explicit `READY` states. Every result carries the originating deterministic payload hash.

## Determinism gate

The TEHNKÉ IR golden replay vector is permanently locked to SHA-256:

`6b358cde668000fd826f03cd018750b3b028d8844d9c7a8e8f98c5dc24bad664`

## Required gate before merge

1. frozen dependency installation succeeds;
2. existing `pnpm check` remains green;
3. TEHNKÉ IR golden replay passes;
4. compatibility bridge tests pass;
5. Matrix Engine tests pass;
6. Web build remains green;
7. no legacy V0.1 compiler source is modified.

A failing infrastructure gate must be diagnosed separately from compiler semantics.
