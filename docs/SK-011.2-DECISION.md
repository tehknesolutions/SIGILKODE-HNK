# ADR — SK-011.2 Matrix boundary

Decision: keep compatibility translation, canonical IR and Matrix execution as separate layers.

Reason: V0.1 preservation and deterministic replay are stronger when legacy parsing cannot directly invoke Matrix behavior. TEHNKE-IR/V0.2 becomes the auditable boundary between intent compilation and Matrix execution.

Consequence: every future canonical Matrix algorithm is implemented as an explicit adapter rather than a conditional hidden inside the compiler.
