# SK-011.2 validation runbook

Use Node 22.x and pnpm 12.x.

1. `pnpm install --frozen-lockfile`
2. `node scripts/validate-sk0112.mjs`
3. `pnpm check`
4. `pnpm build:web`
5. inspect `git diff main...HEAD` and confirm no legacy V0.1 compiler source was edited
6. review CI execution and merge only after all executable gates are green

If frozen installation rejects the repository baseline lockfile, repair that infrastructure defect separately and rerun the complete sequence rather than weakening the gate.
