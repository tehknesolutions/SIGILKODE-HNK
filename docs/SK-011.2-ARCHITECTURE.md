# SK-011.2 architecture

`ALEF → TEHNKE-IR/V0.2 → Matrix Engine → Manifestation descriptors`

Legacy-shaped inputs may enter through:

`SIGIL-IR/V0.1-shaped input → Compatibility Bridge → TEHNKE-IR/V0.2`

The bridge and engine are deliberately separate. Translation decides representation; execution consumes the canonical representation. This prevents Matrix behavior from leaking into legacy parsing and keeps replay hashes anchored to TEHNKE IR.

The Matrix Engine currently performs deterministic software materialization only. Matrix-specific algorithms can be attached in later SK-011 increments behind explicit identity adapters and their own source locks.
