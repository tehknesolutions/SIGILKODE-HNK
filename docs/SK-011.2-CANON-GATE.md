# SK-011.2 canonical adapter gate

A Matrix identity may be named in TEHNKE IR before executable transformation semantics exist. Naming does not authorize implementation assumptions.

Before a non-neutral adapter is activated, it must have:

1. explicit HNK canonical definition;
2. version/revision identifier;
3. source-lock provenance;
4. deterministic input/output vectors;
5. replay tests;
6. compatibility impact review.

Until then, the identity adapter is mandatory.
